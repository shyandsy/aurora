# Aurora Samples

This directory contains sample projects for the Aurora framework. See each sample’s README for how to run it.

| Sample | Description |
|--------|-------------|
| [full_showcase](full_showcase/) | Full application: Server, GORM, Redis, JWT, i18n, migrations, layered structure (controller / service / datalayer), RBAC, auth. |
| [customize_error_handler](customize_error_handler/) | Minimal app: custom error response format (`contracts.ErrorHandler` + `feature.WithErrorHandler`). |
| [geoip](geoip/) | IP → 归属地 本地离线解析,国内库内嵌、零配置 `go run .` 即出结果(`feature/geoip`)。 |
